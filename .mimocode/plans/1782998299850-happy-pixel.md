# Plan: Importar quiz sin necesidad de curso/aula preexistente

## Objetivo
Permitir importar preguntas de quiz desde un CSV que solo tenga las columnas de preguntas (pergunta, opcaoA-D, correta), sin necesidad de incluir curso_titulo/aula_titulo. El usuario selecciona el destino (curso → aula) después de subir el archivo.

## Flujo de usuario

1. Usuario sube un CSV con preguntas (solo columnas: pergunta, opcaoA, opcaoB, opcaoC, opcaoD, correta)
2. Sistema detecta tipo = `quiz_pergunta`
3. **Si el CSV NO tiene columnas de parent** (curso_titulo/aula_titulo):
   - Muestra dropdown de **Curso** (carga la lista de cursos existentes)
   - Muestra dropdown de **Aula** (filtrado por el curso seleccionado)
   - El usuario selecciona destino → se inyectan las columnas faltantes antes de importar
4. **Si el CSV SÍ tiene columnas de parent**: funciona como antes (sin cambio)
5. **CSV mixto** (algunas filas con parent, otras sin): las que faltan usan el selector como fallback
6. Importación normal → resultado con links

### Función para detectar si faltan columnas parent
```ts
const needsParentColumns = (columns: string[]) => {
  const h = columns.map(c => c.toLowerCase().trim());
  return !h.includes("curso_titulo") && !h.includes("curso_id") && 
         !h.includes("aula_titulo") && !h.includes("aula_id");
};
```

### Función para inyectar columnas en CSV
```ts
const injectParentColumns = (csv: string, cursoTitulo: string, aulaTitulo: string): string => {
  const lines = csv.split("\n").filter(l => l.trim());
  const headers = lines[0];
  const hasCurso = headers.toLowerCase().includes("curso_titulo") || headers.toLowerCase().includes("curso_id");
  const hasAula = headers.toLowerCase().includes("aula_titulo") || headers.toLowerCase().includes("aula_id");
  
  let newHeaders = headers;
  if (!hasCurso) newHeaders += ",curso_titulo";
  if (!hasAula) newHeaders += ",aula_titulo";
  
  const dataLines = lines.slice(1).map(line => {
    let row = line;
    if (!hasCurso) row += `,"${cursoTitulo}"`;
    if (!hasAula) row += `,"${aulaTitulo}"`;
    return row;
  });
  
  return [newHeaders, ...dataLines].join("\n");
};
```
